# How to Use This With Claude (Start Here, Dad)

Hey Pops. This is your whole book in one place, set up so Claude can read every chapter
at once and help you write, edit, and sharpen it. No tech skills needed. Just follow these
steps once and you're set.

You already have a Claude account, so you're most of the way there.

---

## The one-time setup (about 5 minutes)

### Step 1: Get the book file
You only need ONE file: **`clarity-compass-FULL-BOOK.md`**. It has every chapter in it.

- On the GitHub page, click the green **Code** button, then **Download ZIP**.
- Open the downloaded folder. The file you want is `clarity-compass-FULL-BOOK.md`.
- (If that's fiddly, just have Brody send you that one file. It's all you need.)

### Step 2: Make a Project in Claude
A "Project" is just a folder inside Claude that remembers your book so you don't have to
paste it in every time.

1. Go to **claude.ai** and sign in.
2. On the left, click **Projects**, then **Create Project**.
3. Name it **Clarity Compass Book**.

### Step 3: Give the book to your Project
1. Open your new Project.
2. Find **Project knowledge** (or the paperclip / "Add content" button).
3. Upload **`clarity-compass-FULL-BOOK.md`**.

That's it. Claude now knows your whole book.

### Step 4: Set the instructions (optional but worth it)
In the Project, find **Set custom instructions** (or "Instructions") and paste in the text
from the file **`claude-project-instructions.md`**. This tells Claude how to act as your
writing partner. Copy it once and forget it.

---

## How to actually use it day to day

Once set up, just open the Project and start a chat. Some things you can say:

- "Read chapter Two (North) and tell me where it drags."
- "I want to add a story here about ___. Where should it go and how do I set it up?"
- "Rewrite this paragraph tighter, keep my voice." (then paste the paragraph)
- "Where in the book do I already talk about identity? I don't want to repeat myself."
- "Is the teaser giving away too much?"
- "Make a list of every story I use, so I can see if I'm leaning on Shackleton too hard."

Claude has the whole book in front of it, so it can answer across chapters, not just the
one you're looking at.

---

## The best part: your own panel of book editors

In the **`editorial-board`** folder there are five expert "editors" you can summon any time.
Each one is a specialist. To use one:

1. Open the file you want (for example `developmental-editor.md`).
2. Copy everything below the line.
3. Paste it into a chat inside your Project.
4. Claude becomes that editor and reviews your book.

The five editors:
- **developmental-editor**: the big picture. Is the whole book working?
- **structural-architect**: does the compass framework hold up?
- **narrative-editor**: are your stories landing?
- **line-editor**: sharper sentences, your voice.
- **reader-advocate**: what a real entrepreneur thinks while reading it.

Want all five at once? Use **`run-the-board.md`**. It runs the whole panel and then gives you
the consensus on the most important changes.

Every editor is told to be brutally honest, the way you asked. They will protect what's working
and tell you straight what isn't.

## When you change the book

When you edit a chapter and want Claude to see the new version, just upload the updated file to
the Project knowledge again (it replaces the old one). If Brody is keeping the GitHub copy
updated, he can hand you a fresh `clarity-compass-FULL-BOOK.md` any time.

That's everything. Go build it. Love you.
